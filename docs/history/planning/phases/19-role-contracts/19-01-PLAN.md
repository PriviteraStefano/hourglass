# Phase 19 Plan 01 — Author the five role contracts

**Goal:** `docs/design/workflows/` holds the five role contracts and an index, each following `19-PATTERNS.md`, each job record carrying id · actor · trigger · steps · surfaces · API interactions · current state · backend-authority note.

**Inputs (read before authoring):** `19-CONTEXT.md` (decisions), `19-RESEARCH.md` (verified facts + gap register), `19-PATTERNS.md` (authoring rules), `docs/design/LANGUAGE.md`, `docs/design/CHROME.md`, `docs/design/INDEX.md`.

## Task 1 — `docs/design/workflows/README.md`

1. Index: one line per contract with its role string and the job-id namespace.
2. Authority statement: LANGUAGE.md wins language, CHROME.md wins chrome, these contracts add jobs/surfaces/composition.
3. Job-id scheme (`E-`, `M-`, `F-`, `H-`, `C-`) with the stability rule and Phase 20 citation note.
4. **Gap register**: G1…G11 verbatim from `19-RESEARCH.md` §8, each with its evidence pointer.
5. Scope note: per-role rows live in each contract; the assembled role×surface matrix is Phase 20 (`COMPOSITION.md`).

## Task 2 — `docs/design/workflows/employee.md` (exemplar)

Jobs E-01…E-11 per the confirmed inventory: capture time · capture expenses · Today landing · follow my submissions · raise internal demand (ticket) · propose an activity · see own coverage · declare absence/unavailability · claim queued WG work · plan own work (`self_planned`) · export own rows.

Must name: the WG manager/delegate hat (cross-reference `M-01`), the org-wide list-read gap (G2), the missing availability write route (G8), and that closing periods / org-wide reporting are **not** employee jobs.

## Task 3 — `docs/design/workflows/manager.md`

Jobs M-01…M-10: approve stage 1 (owns the stage-1 job, incl. WG-hat holders) · set the plan · read plan + capacity · allocate coverage · close period / read snapshot · shape the org (units) · staff the work (WGs) · triage tickets · set planning policy · team exports.

Must name: org-tree work is a manager job and **not Admin/Settings** (SC2/SC4), the ungated unit/WG routes (G3), `RoleGated` manager requirement, and the governance-voting gap (G10).

## Task 4 — `docs/design/workflows/finance.md`

Jobs F-01…F-08: approve stage 2 · own the commercial record · own customer records · own activities · read money labels · govern membership · org-wide reporting · cutoffs (snapshot read + reporting cadence; the close action belongs to `M-05`).

Must name: the export `default`-branch gap (G6) and the invite-customer stub (G7).

## Task 5 — `docs/design/workflows/hr.md`

Jobs H-01…H-05: curate availability windows · curate employment validity · people composition shared with manager · capacity + payroll view · never an approver.

Must name the HR backend gap (G5) as the contract's headline Gap, the read-only availability surface (G8), and the permit-expiry column without a reader (G9). H-03 `MUST` cross-reference the manager org-tree job.

## Task 6 — `docs/design/workflows/customer.md`

C-01…C-03: no app surface (decision + rationale) · the internal jobs that serve customers, each cross-referenced to its owning contract+job id · what would reopen the decision.

Must record the provenance gap: D-E survives only as secondhand citations in `ADR-P-003` (G11).
