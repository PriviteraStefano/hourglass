# Requirements: Hourglass

**Defined:** 2026-06-08
**Core Value:** Role-based approval workflows (employee → manager → finance) with hierarchical organization structures, contract/project management, and export capabilities.

## v0.1 Requirements

Requirements for the remaining v0.1 work. Previous phases (Pg-1/Pg-2/Pg-3 — PostgreSQL migration) are already validated.

- [x] **TEST-03**: Service-layer tests rewritten to run against real PostgreSQL via testcontainers

- [x] **TEST-05**: All bugs discovered during test rewrite fixed — 12+ documented bugs fixed, full suite green with zero skipped tests (00-05, 00-09)
- [x] **TEST-06**: Playwright E2E verified against PostgreSQL backend

- [x] **AUTH-04**: AppShell with user profile, org switcher, logout

- [x] **ORG-05**: Delete protection — cannot delete unit with children or members, root unit cannot be deleted

- [x] **CUST-05**: Internal customer (organization itself) visual indicator with badge
- [x] **CUST-06**: Empty state when no customers

### Contracts

- [x] **CTRT-01**: Contract list page with filtering (status, org) — owned/internal tabs + status filter + search
- [x] **CTRT-02**: Create contract with customer dropdown — incl. search + "(Internal)" suffix (04-02)
- [x] **CTRT-03**: Edit contract — inline edit on detail page (finance-gated)
- [x] **CTRT-04**: Delete contract — blocked if has active projects (HasProjects check)
- [x] **CTRT-05**: Projects list displayed on contract detail page — superseded by activity tree after Phase 9
- [x] **CTRT-06**: "Internal customer" option in customer selector
- [x] **CTRT-07**: Zero-value contracts allowed

### Projects

- [x] **PROJ-01**: Project list page with filtering (contract_id, org_id, type: billable/internal) — superseded by activities surface (Phase 9)
- [x] **PROJ-02**: Create project (name, type, contract, governance model, scope) — superseded by activity create (Phase 9)
- [x] **PROJ-03**: Edit project — EditProjectDialog completed — superseded by activity edit (Phase 9)
- [x] **PROJ-04**: Delete project — blocked if has time entries or subprojects — superseded by activity delete guard (Phase 9)
- [x] **PROJ-05**: Subproject list on project detail — superseded by recursive activity children (Phase 9)
- [x] **PROJ-06**: Adopted projects display creation org — superseded by activity commercial-context resolution (Phase 9)

> Projects/subprojects were replaced by the recursive **Activity** model in Phase 9 (ADR-P-007) — the PROJ-* requirements shipped in Phase 5, then were superseded. The activity model delivers their intent: `/activities` list/detail with kind filters, ancestry, commercial context, and billability.

### Time Entries

- [x] **TIME-01**: Time entry list with filtering (status, date range, project, user) — filterable list view + calendar (08-02)
- [x] **TIME-02**: Create time entry (date, hours, activity, unit/WG, description) — flat model (06-04)
- [x] **TIME-03**: Edit time entry (draft/submitted only)
- [x] **TIME-04**: Submit for approval
- [x] **TIME-05**: Cannot edit approved/rejected entries
- [x] **TIME-06**: Cannot delete entries with approvals
- [x] **TIME-07**: Employee cannot self-approve
- [x] **TIME-08**: Manager cannot approve own entries

### Expenses

- [x] **EXPN-01**: Expense list with filtering (status, date range, project, category) — filterable list view + calendar (08-02)
- [x] **EXPN-02**: Create expense (date, amount, category, activity, description) — incl. receipt upload (06-05)
- [x] **EXPN-03**: Edit expense (draft/submitted only)
- [x] **EXPN-04**: Submit for approval
- [x] **EXPN-05**: Expense categories: mileage, meal, accommodation, other
- [x] **EXPN-06**: Same approval workflow constraints as time entries

### Approval Workflow

- [x] **APPR-01**: Approval history is immutable — `*_approvals` append-only tables
- [x] **APPR-02**: Rejected entries show reason — reason-required reject (10-05)
- [x] **APPR-03**: Approval workflow: employee creates → submits → manager approves → finance approves/rejects — routing via activity → WG → manager/delegate chain (09-04)
- [x] **APPR-04**: Status badge component showing current state — six distinct states (08-02)
- [x] **APPR-05**: Approval buttons component (approve/reject) for managers & finance — /approvals queue (10-05)

### Exports

- [x] **EXPT-01**: Timesheet export (CSV/Excel) with date range filter
- [x] **EXPT-02**: Expense export (CSV/Excel) with date range filter
- [x] **EXPT-03**: Combined export with both time + expense data
- [x] **EXPT-04**: Download as file — XLSX via excelize (backend) + useDownload hook (frontend)
- [x] **EXPT-05**: Empty export shows friendly message
- [x] **EXPT-06**: Auth required — user-scoped data only
