### 60/30/10 Distribution

| Layer | Coverage | CSS Variable | Elements |
|-------|----------|-------------|----------|
| Dominant surfaces (60%) | Page backgrounds, cards, dialog surfaces | `--background`, `--card`, `--popover` | `bg-background`, `bg-card` |
| Secondary surfaces (30%) | Sidebar, muted backgrounds, accent hover | `--sidebar`, `--muted`, `--accent` | `bg-sidebar`, `bg-muted`, `bg-accent` |
| Accent (10%) | Primary actions, focus states, badges | `--primary` | Primary buttons, Badge `default`, Select focus, active tabs |

**Accent (primary-400 green-teal) reserved for:**
- Primary action buttons ("Create Project", "Save Changes", "Adopt")
- Active tab indicator (TabsTrigger active state)
- Billable project badges (Badge variant="default")
- Focus rings on form inputs
- Links and interactive text
- UI accent borders and highlights

**Destructive reserved for:**
- Delete button (`variant="destructive"`)
- Delete confirmation dialog action button
- Error toast messages
- 409 error message display in dialogs
- Any `text-destructive` labels

## Interaction States

### Edit Project Dialog

| State | Visual | Behavior |
|-------|--------|----------|
| **Closed** | Not rendered | Triggered by "Edit" button on detail page |
| **Opening** | Dialog slides in with backdrop | Pre-populate all fields from current project data via `projectQueryOpts` |
| **Editing** | Form with pre-filled fields | Fields: Name (Input), Type (Select: billable/internal), Contract (Select), Governance Model (Select), Shared (Checkbox). All fields editable per D-02. |
| **Submitting** | Submit button shows spinner + "Saving...", fields disabled | Calls `PUT /projects/{id}` with `UpdateProjectRequest` |
| **Success** | Dialog closes automatically | Toast: "Project updated". Invalidates `['projects']` and `['projects', id]` query keys. Detail page refreshes with updated data. |
| **Error** | Toast with error message | `toast.error(error.message)`. Dialog stays open for retry. |
| **Cancel** | Dialog closes, no changes | Form state discarded. |

### Delete Confirmation

| State | Visual | Behavior |
|-------|--------|----------|
| **Closed** | Not rendered | Triggered by "Delete" button on detail page |
| **Opening** | AlertDialog slides in with destructive accent | Title: "Delete {project name}?" |
| **Awaiting confirmation** | Warning text + two buttons: Cancel (outline), Delete (destructive) | Copy: "Are you sure you want to delete {project name}? This will also remove all adoption records and cannot be undone." |
| **Submitting** | Delete button shows spinner + "Deleting..." | Calls `DELETE /projects/{id}`. Cancel button remains clickable. |
| **Success** | Dialog closes, navigate to `/projects` list | Toast: "Project deleted". Invalidates `['projects']` query key. |
| **409 Blocked** | Inline error text inside dialog (not toast) | Shows backend error message (e.g., "Project has active time entries" or "Subproject has active time entries"). Dialog stays open. User can close and investigate. |
| **Other error** | Toast with error message | `toast.error(error.message)`. Dialog stays open. |
| **Cancel** | Dialog closes | No action. |

### Subproject Expandable Section

| State | Visual | Behavior |
|-------|--------|----------|
| **Collapsed** | Section header: "Subprojects (3)" with chevron icon | Shows count. Click to expand. |
| **Loading** | Skeleton rows inside expanded section | `useQuery` with `enabled` tied to expanded state — fetches only on first expand. |
| **Loaded** | List of subproject rows | Each row: subproject name, status badge (active/inactive), description snippet |
| **Empty** | Empty state component | Copy: "No subprojects for this project. Subprojects can be created for deeper tracking." |
| **Error** | Inline error message | Copy: "Failed to load subprojects." with retry button. |
| **Re-collapse** | Section collapses, content hidden | Data remains cached (`staleTime: 5min`). Re-expanding reuses cached data. |

### Project Detail Page (existing, modified)

| State | Visual | Behavior |
|-------|--------|----------|
| **Loading** | "Loading..." centered text (existing) | Skeleton or text placeholder |
| **Not found** | "Project not found" centered text (existing) | When project ID doesn't exist |

### Tab Scopes (existing, no changes)

## Accessibility

| Pattern | Requirement |
|---------|-------------|
| Dialog focus trap | Built into shadcn Dialog component |
| AlertDialog role | Built into shadcn AlertDialog component |
| Form labels | Use `<label>` element with htmlFor pointing to `<Input>` id. Existing create dialog uses `text-sm font-medium` label pattern. |
| Select keyboard nav | Built into shadcn Select |
| Skip links | Provided by existing AppShell |
| Color contrast | OKLCH base colors meet WCAG AA. Primary-400 on white = ~4.5:1 contrast. |
| Focus indicators | `outline-ring/50` ring on all interactive elements (set in index.css) |
| Reduced motion | Handled by tw-animate-css prefers-reduced-motion queries |
