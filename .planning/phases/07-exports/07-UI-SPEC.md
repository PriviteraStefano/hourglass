## Interaction Contract

### Download Flow

```
User fills form (date range, format, filters)
  → clicks "Download" button
    → useDownload hook:
      1. Check count endpoint (if count=0 → toast "No data to export", stop)
      2. Fetch GET /api/exports/{type}?from=&to=&format=csv|xlsx&project_id=&user_id=
         with credentials:include + AbortController 60s timeout
      3. Check Content-Type header:
         - text/csv or application/vnd.openxmlformats → success → blob → download
         - application/json → parse error → toast "Export failed. Please try again."
      4. Toast states:
         - Loading: "Generating export..."
         - Success: "Download started"
         - Error: "Export failed. Please try again."
    → Button shows spinner + "Downloading..." during isPending
    → Button disabled during download
```

### Export Tab Switching (Time-Entries and Expenses Pages)

```
Tab bar: [List] [Calendar] [Export]
  - Default: "List" tab active
  - Switching to "Export": content area replaced by ExportForm component
  - Switching away from "Export": previous view restored (no state preserved beyond form)
  - Export tab has no count badge — format selector is always visible
```

### Date Range Picker

```
Calendar popover + preset buttons:
  - Preset buttons: "This Month", "Last Month", "This Quarter", "This Year"
  - Clicking preset: updates range state AND calendar visual selection
  - Calendar trigger button shows: "dd MMM yyyy – dd MMM yyyy" format
  - Default: current month (1st → last day)
  - Validation: from < to (client-side), max 1 year range
  - Validation error: inline message "Date range must be within 1 year"
```

### Format Selector

```
Segmented control: [CSV] [XLSX]
  - Default: CSV selected
  - Visual: Button group with active state highlighting
  - Active tab uses bg-primary / text-primary-foreground
  - Inactive tab uses default button variant
```

### Empty State (Count Pre-Check)

```
1. User sets up form fields
2. User clicks "Download"
3. useDownload fires count query first
4. If count === 0:
   - Show toast: "No data to export"
   - Do NOT trigger download request
   - Button returns to idle state
5. If count > 0:
   - Proceed with download fetch
```

### Mobile Layout (D-32)

```
- Same form stacks vertically (flex-col on small screens)
- Calendar picker becomes modal popover on mobile
- Preset buttons become horizontal scroll (overflow-x-auto)
- Format segmented control wraps or stays horizontal
```

## States Summary

| Component | States |
|-----------|--------|
| Export form | Default (idle, current month pre-filled) → Validating (client-side date check) → Checking count → Downloading (button spinner + disabled) → Success (toast) / Error (toast) |
| Download button | Idle ("Download") → Pending ("Downloading..." + spinner) → Disabled (during download) → Re-enabled (after success/error) |
| Format selector | CSV selected (default) | XLSX selected — mutually exclusive toggle |
| Calendar trigger | Filled ("dd MMM yyyy – dd MMM yyyy") | Empty ("Select date range") on initial mount before any selection |
| Count pre-check | Waiting (call in-flight) → Zero (toast "No data to export", stop) → Positive (proceed to download) |
| Toast (sonner promise) | Loading ("Generating export...") → Success ("Download started") → Error ("Export failed. Please try again.") |
| Tab bar | List (default active) | Calendar | Export — mutually exclusive, no multi-select |
