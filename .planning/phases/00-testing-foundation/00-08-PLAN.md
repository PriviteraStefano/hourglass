  <action>
    Create `web/e2e/time-entries.spec.ts`:

    Follow auth.spec.ts pattern:
    - Use `test.describe('Time Entries CRUD', () => { ... })`
    - Create a `testId` prefix using `Date.now()` for unique data
    - Use `test.beforeAll` to register a user and login via API (`request.post` at `http://localhost:8080/auth/register` and `http://localhost:8080/auth/login`)
    - Store cookies from login response for subsequent API calls

    Test cases (each as `test('...', async ({ page, request }) => { ... })`):

    1. `'create time entry'`:
       - Login via API first (using request.post to get cookies)
       - Navigate to /time-entries
       - Click "Create" or "Add" button
       - Fill form: project, date, hours, description
       - Submit form
       - Verify success (toast/notification, or entry appears in list)

    2. `'view time entry details'`:
       - API-seed a time entry
       - Navigate to /time-entries
       - Click on the entry
       - Verify details page shows correct data

    3. `'edit time entry'`:
       - API-seed a time entry
       - Navigate to edit
       - Change hours/description
       - Save
       - Verify updated data

    4. `'delete time entry'`:
       - API-seed a time entry
       - Navigate to delete
       - Confirm deletion
       - Verify entry no longer in list

    5. `'submit time entry for approval'`:
       - API-seed a draft entry
       - Navigate to submit
       - Verify status changed to submitted

    Create `web/e2e/projects.spec.ts`:

    Same pattern:

    1. `'create project'` — create billable project with name, type, contract association
    2. `'view project'` — API-seed, navigate, verify details
    3. `'edit project'` — change name/type
    4. `'deactivate project'` — soft delete

    For data seeding, use `request.post` with cookies from login:
    ```typescript
    const loginRes = await request.post('http://localhost:8080/auth/login', {
      data: { email, password }
    })
    const cookies = loginRes.headers()['set-cookie']
    ```
    Then create entities via API:
    ```typescript
    await request.post('http://localhost:8080/time-entries', {
      data: { ... },
      headers: { Cookie: cookies }
    })
    ```

    Use async/await, expect().toHaveURL(), expect().toBeVisible() patterns from auth.spec.ts.
    Add `{ timeout: 10000 }` for navigation waits.
