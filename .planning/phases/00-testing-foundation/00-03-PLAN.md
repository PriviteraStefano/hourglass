<objective>
Rewrite service-layer tests to run against real PostgreSQL via testcontainers. Per D-10, keep existing in-memory mock tests for pure business logic while adding testcontainer-backed tests for repository interaction. Per D-12, new tests go in separate `_integration_test.go` files.

Purpose: The current service tests use in-memory mocks that never exercise SQL query logic, constraint validation, or real database behavior. By running against a real PostgreSQL container, we catch SQL errors, constraint violations, and data integrity issues at the service-test level.

Output: New `_integration_test.go` files in each core service package, each with a TestMain that starts a testcontainer PostgreSQL instance, and per-function schema lifecycle management.
</objective>
