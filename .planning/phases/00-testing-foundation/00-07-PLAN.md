    2. `"handles error response"`:
       - Mock GET /api/test returns 400 with `{ error: 'bad request' }`
       - Call api('/test')
       - Assert: throws Error('bad request')

    3. `"handles 401 then refresh then retry succeeds"` (critical — tests the auto-refresh flow):
       - Mock GET /api/protected returns 401 on first call, 200 on second call
       - Mock POST /api/auth/refresh returns 200 (refresh succeeds)
       - Call api('/protected')
       - Assert: second call to /api/protected succeeds, returns data (the retry worked)

    4. `"handles 401 then refresh fails"`:
       - Mock GET /api/protected returns 401
       - Mock POST /api/auth/refresh returns 401 (refresh fails)
       - Call api('/protected')
       - Assert: error is thrown (no more retries)

    5. `"sets Content-Type and Accept headers"`:
       - Mock endpoint that checks headers
       - Assert: Content-Type: application/json and Accept: application/json

    6. `"handles network error"`:
       - Mock endpoint that throws network error
       - Call api('/test')
       - Assert: throws Error

    For the 401→refresh→retry tests, use `server.use()` with `http.post('/api/auth/refresh', ...)` and a counter or conditional response for the protected endpoint.
