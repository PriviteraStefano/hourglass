# Plan 10-04 — Today landing page

<threat_model>

| Threat | Severity | Mitigation |
|--------|----------|------------|
| T-10-04-1: Today becomes a dashboard (charts/KPIs creep) | high | ADR-P-004 boundary enforced by review: read-only composition, no new state, no charts — acceptance criteria assert section composition only |
| T-10-04-2: Blank render for edge states (new user, all-caught-up, query error) | high | "never blank" rule: two locked empty states + error state; unit tests reach each |
| T-10-04-3: "Waiting on you" leaks to non-approvers (e.g. pending data rendered for employee) | high | Section gated by `deriveApprovalStages` (Plan 02 helper); pending queries `enabled: stages.length > 0` so no 403 spam; backend remains authoritative |

</threat_model>

## Context

ADR-P-011 D-2: landing is Today from v0.1, ticketless composition admitted. P-004 design rules bind from day one: **read-only composition** (no new state), **one answer, not a dashboard** (no charts/KPIs), **never blank**. Current landing (`routes/_authenticated/index.tsx`) is `<Navigate to="/time-entries" replace />` — replaced by the Today page.

Composition (top-down, no side-by-side competing cards):

1. **Header** (shell): Greeting/title "Today" at Display 28px (`text-3xl font-semibold` — single largest text on any Phase 10 surface) + primary CTA right-aligned: "Review now" (approvers) → `/approvals`, else "Log time" → `/time-entries`
2. **"Waiting on you"** section — renders ONLY if `deriveApprovalStages(profile, workingGroups).length > 0`: pending approvals count/list preview (from `pendingTimeEntriesQueryOpts` + `pendingExpensesQueryOpts`, both `enabled: stages.length > 0`), accent CTA link "Review now"
3. **"Your week"** section — own draft/submitted/rejected entries this week: reuse `timeEntriesForMonthQueryOpts(month, year)` and filter client-side to the current ISO week (`date-fns` `startOfWeek`/`endOfWeek`/`isWithinInterval`), statuses `draft|submitted|rejected` (approved entries are done — exclude); entry cards with `StatusBadge` unchanged; `.font-text` for numeric hours
4. **Locked empty states**:
   - Nothing pending + no week entries → heading "You're all caught up", body "Nothing is waiting on you. When drafts, rejections, or approvals land, they'll show up here."
   - No data at all (new user) → heading "Welcome to Hourglass", body "Start by logging time against an activity. Your week and anything waiting on you will appear here.", CTA "Log time"
5. **Error state**: "We couldn't load Today. {reason}. Try again." — route `errorComponent` + `router.invalidate()` convention, rendered inside Body
