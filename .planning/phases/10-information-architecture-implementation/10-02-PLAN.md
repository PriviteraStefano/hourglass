## Context

ADR-P-011 D-1 replaces the mechanic-named groups (Tracking/Management) with job-language, pillar-mapped groups. D-5 scopes the sidebar per org role + WG approval stage. The role is already in route context (`_authenticated.tsx` beforeLoad → `profile`), and WG manager/delegate membership is derivable from `GET /working-groups` payloads (`manager_id`, `delegate_ids`) + `auth/me.user.id` — no new backend endpoint (RESEARCH §2.1 recommendation).

Locked group structure (render order, exact casing):

1. **Today** — `/` (ungrouped top item)
2. **Track** — Time `/time-entries` · Expenses `/expenses` · Tickets `disabled`, tooltip "Tickets arrive in v0.2"
3. **Work** — Activities `/activities` · Working Groups `/working-groups`
4. **People** — Org `/org-hierarchy` · Availability `disabled`, tooltip "Availability lands with the staffing schema"
5. **Economics** — Contracts `/contracts` · Customers `/customers`
6. **Review** — Approvals `/approvals`
7. **Reports** — Exports `/exports`
8. **Admin** — Settings `disabled`

Visibility matrix (v0.1 implementable subset, from RESEARCH §2.6):

| Group | employee | employee+WG stage | manager | finance | hr |
|-------|----------|-------------------|---------|---------|----|
| Today, Track, People, Reports | ✓ | ✓ | ✓ | ✓ | ✓ |
| Work | ✓ | ✓ | ✓ | ✓ | ✓ |
| Economics | — | — | ✓ | ✓ | ✓ |
| Review | — | ✓ (Manager) | ✓ (Manager) | ✓ (Finance) | **never** |
| Admin | — | — | — | — | — (hidden from all; no org-admin role exists yet) |

Note: Economics hidden from employee (ADR matrix) — a change from today's flat nav; HR keeps Economics read per ADR ("read (payroll link)").
