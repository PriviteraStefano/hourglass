## STRIDE Threat Register

| Threat ID | Category | Component | Disposition | Mitigation Plan |
|-----------|----------|-----------|-------------|-----------------|
| T-06-09 | Denial of Service | ReceiptUpload handler | mitigate | `http.MaxBytesReader(w, r.Body, 10<<20)` limits upload to 10MB. Extension validation rejects non-PDF/JPEG/PNG. |
| T-06-10 | Tampering | Expense handler input | mitigate | Handler parses and validates all fields (project_id non-empty, amount>0, category non-empty) before forwarding to service. Domain model's IsValidCategory provides secondary gate. |
| T-06-11 | Information Disclosure | Receipt file enumeration | mitigate | Receipt URLs use UUID-based paths (`uploads/receipts/{org_id}/{expense_id}/{filename}`). No sequential IDs. |
| T-06-12 | Elevation of Privilege | Role-based endpoint gating | mitigate | All expense routes use `middleware.Auth`. Approve/Reject handlers check `middleware.GetRole()` and reject non-manager/finance roles with 403. |
</threat_model>
