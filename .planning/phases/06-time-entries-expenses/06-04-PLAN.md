<interfaces>
**Backend API contracts consumed by this plan:**

```
GET  /time-entries?date=YYYY-MM-DD -> TimeEntry[]
GET  /time-entries?month=M&year=YYYY -> TimeEntry[]
GET  /time-entries/{id} -> TimeEntry
POST /time-entries -> 201 TimeEntry
PUT  /time-entries/{id} -> TimeEntry
DELETE /time-entries/{id} -> 204
POST /time-entries/{id}/submit -> TimeEntry
POST /time-entries/{id}/approve -> TimeEntry (role from JWT)
POST /time-entries/{id}/reject -> TimeEntry  (body: { reason: string })
GET  /time-entries/pending -> TimeEntry[]
```

**TimeEntry response shape (flat, no items):**
```typescript
interface TimeEntry {
  id: string
  org_id: string
  user_id: string
  project_id: string
  subproject_id: string
  wg_id: string
  unit_id: string
  hours: number
  description: string
  entry_date: string
  status: EntryStatus
  current_approver_role?: 'manager' | 'finance'
  submitted_at?: string
  created_at: string
  updated_at: string
}
```
</interfaces>
