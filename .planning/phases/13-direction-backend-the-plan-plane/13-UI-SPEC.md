| Element | Copy |
|---------|------|

| Empty state body | N/A — no UI surface this phase |

| Destructive confirmation | N/A for UI. Backend contract: cancellation of a direction row (D-13-10) and unclaim (D-13-16) **require a reason** — API rejects reason-less destructive writes with 400. Future UI (Phase 19) must present a required-reason confirm dialog; the API enforces the invariant server-side regardless |
