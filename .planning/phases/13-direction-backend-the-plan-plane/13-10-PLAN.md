<decision_record>
**WR-03 decision (required by 13-VERIFICATION.md gap 5):** write `AuditActionUnclaimed`
('unclaimed') from `Service.Unclaim`. Rationale: ADR-BE-018 §3 already pins the
vocabulary `created / activated / cancelled / superseded / claimed / unclaimed` —
the ADR is the record of truth and needs NO amendment; the drift is in the code
and the port doc. Aligning code to the ADR keeps unclaim events distinguishable
from cancels for Phase 19 history filters (the ADR's stated purpose, T-13-06) and
makes the exported constant live instead of a trap. The alternative (delete the
constant + amend ADR-BE-018 §3) would churn the record of truth to match a
less-distinguishing behavior. This reverses the earlier 13-05 note ("AuditActionUnclaimed
stays a pinned vocabulary constant, never written by the unclaim path") — record
the reversal in the SUMMARY. Reversibility: `reversible` (one line + docs).
</decision_record>
