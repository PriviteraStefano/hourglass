## Directory Purposes

**`cmd/server/`**
- Purpose: Composition root — the only place objects are constructed
- Contains: `main.go` (env, pool, full DI, ~100 route registrations, middleware stack)
- Key files: `cmd/server/main.go`, `cmd/server/main_test.go`

**`cmd/migrate/`**
- Purpose: Apply/rollback migrations against `DATABASE_URL`
- Contains: `main.go` with `-up`/`-down` flags and `-dir` override
- Key files: `cmd/migrate/main.go`

**`internal/core/domain/`**
- Purpose: Pure business models with behavior methods and sentinel errors; no external deps beyond `google/uuid`
- Contains: 14 bounded contexts: `auth`, `organization`, `unit`, `working_group`, `activity`, `contract`, `customer`, `time_entry`, `expense`, `invitation`, `password_reset`, `ticket`, `coverage`, `audit`
- Key files: `internal/core/domain/time_entry/time_entry.go` (reference: statuses, `CanEdit()`, `IsOwner()`)

**`internal/core/ports/`**
- Purpose: Interfaces the core requires (repositories, token service, hasher, finder) + `errors.go`
- Contains: 21 interface files, one per persistence/service capability
- Key files: `internal/core/ports/errors.go`, `internal/core/ports/time_entry_repository.go`

**`internal/core/services/`**
- Purpose: Application business logic — one package per bounded context; also `routing/` (shared approval resolution) and `testdata/` (mocks, factories for service tests)
- Contains: `auth`, `organization`, `unit`, `working_group`, `activity`, `contract`, `customer`, `time_entry`, `expense`, `invitation`, `password_reset`, `ticket`, `coverage`, `export`, `routing`, `testdata`
- Key files: `internal/core/services/time_entry/time_entry.go`, `internal/core/services/routing/routing.go`

**`internal/adapters/primary/http/`**
- Purpose: Thin HTTP handlers — parse, delegate, respond
- Contains: `auth.go`, `time_entry.go`, `expense.go`, `contract.go`, `activity_handler.go`, `ticket_handler.go`, `coverage_handler.go`, `unit.go`, `working_group.go`, `customer.go`, `organization.go`, `invitation.go`, `password_reset.go`, `export.go`, `validate.go` + `*_test.go` files
- Key files: `internal/adapters/primary/http/time_entry.go` (reference handler pattern)

**`internal/adapters/secondary/postgres/`**
- Purpose: PostgreSQL repository implementations of `ports.*`
- Contains: one repo file per port + `postgres.go` + `test_setup.go`/`exported_test_helpers.go` (testcontainers infra)
- Key files: `internal/adapters/secondary/postgres/time_entry_repository.go`, `internal/adapters/secondary/postgres/postgres.go`

**`internal/` support packages**
- `internal/auth/` — `auth.go` (JWT HS256 + bcrypt), `token_service.go` (adapter for `ports.TokenService`), `password_hasher.go`
- `internal/middleware/` — `middleware.go` (Auth/TryAuth/RequireRole/context helpers), `cors.go`, `ratelimit.go`, `version.go`, `logging`
- `internal/db/` — `db.go` (pgxpool wrapper: 25 open / 5 idle), `migrate.go`
- `internal/models/models.go` — legacy enums + DTOs (transitional; see ARCHITECTURE.md anti-patterns)
- `internal/handlers/health_handler.go` — health endpoint

**`pkg/api/`**
- Purpose: Shared JSON envelope `{ data }` / `{ error }`
- Key files: `pkg/api/response.go`

**`migrations/`**
- Purpose: Versioned schema. 34 files (17 numbered pairs: `000` → `020`), each `NNN_name.up.sql` + `NNN_name.down.sql`
- Key files: `migrations/000_full_schema.up.sql` (baseline), `019_coverage_allocations.up.sql`, `020_coverage_snapshots.up.sql`

**`web/src/`**
- `web/src/api/` — per-resource `XxxApis` modules (`auth.ts`, `time-entries.ts`, `expenses.ts`, `activities.ts`, `contracts.ts`, `customers.ts`, `units.ts`, `working-groups.ts`, `exports.ts`) + `__tests__/`
- `web/src/routes/` — `__root.tsx` (providers), `_auth.tsx` (unauthenticated guard) + `_auth/` (login, register, password-reset, invite, bootstrap), `_authenticated.tsx` (auth guard + AppShell) + `_authenticated/` (today, time-entries, expenses, activities, approvals, contracts, customers, working-groups, org-hierarchy, exports)
- `web/src/components/` — `ui/` (shadcn primitives), `layout/` (app-shell, sidebar, header, body, route-error), `shared/` (entries-table, status-badge, entries-filters), `approval/` (approval-buttons, approval-history), `exports/` (export-form), `app/` (org-switcher, profile-menu), `theme-provider.tsx`
- `web/src/lib/` — `api.ts`, `query-client.ts`, `utils.ts`, `role-visibility.ts`, `list-filters.ts`, `use-download.ts`
- `web/src/types/` — `index.ts` (re-exports), `api.ts`, `models.ts`, `unit.ts`, `expense-types.ts`
- `web/e2e/` — Playwright specs per domain (`auth.spec.ts`, `time-entries.spec.ts`, `approvals.spec.ts`, ...) + `helpers.ts`

**`openwiki/` & `plans/` & `graphify-out/`**
- `openwiki/` — repo documentation: `quickstart.md`, `architecture/`, `domain/`, `operations/`, `testing/`
- `plans/` — `hexagonal-migration.md` (target structure), other phase plans
- `graphify-out/` — generated knowledge graph (see `graphify-out/GRAPH_REPORT.md`)

## Key File Locations

**Entry Points:**
- `cmd/server/main.go`: Backend server + route table
- `cmd/migrate/main.go`: Migration CLI
- `web/src/main.tsx`: Frontend entry (router + QueryClient)

**Configuration:**
- `Makefile`: build/run/test/docker targets
- `docker-compose.yml`: postgres + app services
- `web/vite.config.ts`: dev proxy `/api → :8080`, `@` alias, TanStack Router plugin
- `web/package.json`, `bun.lock`: frontend deps (Bun)
- `go.mod` / `go.sum`: backend deps
- `web/components.json`: shadcn/ui config
- `web/playwright.config.ts`, `web/vitest.config.ts`: frontend test configs

**Core Logic:**
- `internal/core/services/*/`: business rules per bounded context
- `internal/core/services/routing/routing.go`: shared manager-stage resolution (ADR-BE-014)
- `internal/adapters/secondary/postgres/*.go`: all SQL
- `internal/middleware/middleware.go`: auth context injection

**Testing:**
- Go unit + integration tests co-located (`*_test.go`, `*_integration_test.go`); `internal/adapters/secondary/postgres/test_setup.go` (testcontainers); `internal/core/services/testdata/` (mocks + factories)
- Frontend Vitest: `web/src/**/__tests__/*.test.ts(x)`; E2E: `web/e2e/*.spec.ts`

## Naming Conventions

**Go files:**
- snake_case: `time_entry_repository.go`, `refresh_token_repo.go` (repo files) vs `contract_repository.go` — mixed `repo`/`repository` suffix between contexts
- Handlers: `auth.go`, `time_entry.go`, `ticket_handler.go`, `coverage_handler.go` — `*_handler.go` used only where the file name would collide or for newer contexts
- Tests: `file_test.go` (unit), `file_integration_test.go` (testcontainers)

**Go symbols:**
- Constructors: `NewXxxRepository(pool)`, `NewXxxService(...)`, `NewXxxHandler(...)`
- Handlers: `type XxxHandler struct { service *xxxsvc.Service }`; methods named after HTTP verbs/actions: `List`, `Create`, `Get`, `Update`, `Delete`, `Submit`, `Approve`, `Reject`
- Services: `type Service struct` in package-per-context (`time_entry.Service`), methods `List/Get/Create/Update/Delete/Submit/Approve/Reject`
- Domain errors: `Err<Condition>` sentinels; port errors: `ErrNotFound`, `ErrConflict`
- Routes: kebab-case paths (`/time-entries`, `/working-groups`, `/coverage/to-cover`)

**Frontend files:**
- kebab-case for all source files: `time-entries-page.tsx`, `status-badge.tsx`, `query-client.ts`
- Route files: `index.tsx` for folder routes, `$id.tsx` for dynamic segments
- Route-local folders: `-components/` (dash-prefixed, excluded from route tree), `-context/`, `-components/dialogs/`, `-components/__tests__/`
- Tests: `__tests__/*.test.ts(x)` dirs co-located

**Frontend symbols:**
- API modules: `XxxApis` namespace object with `*QueryOpts` / `*MutationOpts` factories (`TimeEntriesApis`, `AuthApis`)
- Components: PascalCase (`AppShell`, `StatusBadge`, `OrgHierarchyPage`)
- Query keys: `as const` tuple arrays (`["time-entries", "month", month, year]`)
- Path alias: `@/` → `web/src` (`@/lib/api.ts`)

## Where to Add New Code

**New backend feature (vertical slice — follow hexagonal migration):**
1. Domain model: `internal/core/domain/<context>/<name>.go` (or extend existing context)
2. Port interface: `internal/core/ports/<name>_repository.go` (or extend existing)
3. Service: `internal/core/services/<context>/<name>.go` with `NewService(...)`
4. Handler: `internal/adapters/primary/http/<name>.go`
5. Repository: `internal/adapters/secondary/postgres/<name>_repository.go`
6. Wire everything + register routes in `cmd/server/main.go`
7. Migration pair: `migrations/0NN_<feature>.up.sql` + `.down.sql`
8. Tests: unit `_test.go` co-located; integration `_integration_test.go` (postgres) or `testdata` mocks (service)

**New frontend feature/page:**
1. Types: `web/src/types/api.ts` / `web/src/types/models.ts` (or context file like `unit.ts`)
2. API module: `web/src/api/<resource>.ts` exporting `XxxApis`
3. Route: `web/src/routes/_authenticated/<feature>/index.tsx` (guard inside `_authenticated.tsx` is automatic); co-locate components in `web/src/routes/_authenticated/<feature>/-components/`; use `$id.tsx` for detail routes
4. Shared UI: reuse `web/src/components/ui/*` (shadcn) and `web/src/components/shared/*`; put genuinely cross-domain components in `web/src/components/<area>/`
5. Tests: `-components/__tests__/*.test.tsx` (Vitest) + `web/e2e/<feature>.spec.ts` (Playwright)

**New middleware / cross-cutting concern:**
- Backend: `internal/middleware/<name>.go` + wrap in the stack at `cmd/server/main.go:314`
- Frontend: `web/src/lib/<name>.ts` or `web/src/components/<area>/`

## Special Directories

**`web/src/routeTree.gen.ts`:**
- Purpose: Auto-generated route tree from `web/src/routes/`
- Generated: Yes (TanStack Router Vite plugin)
- Committed: Yes

**`migrations/`:**
- Purpose: Versioned schema + seed data
- Generated: No
- Committed: Yes — treat as append-only (new pairs only)

**`graphify-out/`:**
- Purpose: Generated knowledge graph (`GRAPH_REPORT.md`, `wiki/`)
- Generated: Yes
- Committed: Yes

**`openwiki/`, `plans/`, `docs/`:**
- Purpose: Repo documentation, migration plans, ADRs
- Generated: No
- Committed: Yes

**`uploads/`:**
- Purpose: Local filesystem for receipt uploads (expense receipts)
- Generated: Runtime data
- Committed: No

**`bin/`, `dist/`, `test-results/`, `playwright-report/`:**
- Purpose: Build/test artifacts
- Generated: Yes
- Committed: No
